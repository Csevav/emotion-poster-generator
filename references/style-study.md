## 综合结论

这套语言不是固定模板，而是一套注意力分配方法：大部分画布保持安静，一个图像碎片承担情绪，文字承担方向、距离和节奏。图像告诉观者“看哪里”，文字决定观者“如何移动视线”。

它最容易被误学成三种表面套路：

1. 白底中间放一张小图，下面加整齐标签。
2. 米黄色纸张加档案编号和天气数据。
3. 随机散落字母，假装实验排版。

真正稳定的特征是：图像、主句、碎片文字和空白之间存在清楚的视觉力线；每个元素都承担不同角色，没有两个元素重复解释同一件事。

## 构图统计式观察

- 空白通常约占 68%-92%，并非所有作品都追求极端空白。文字主导或蓝点场可以降低到约 65%-78%。
- 主视觉簇通常占 8%-26%。水果、人物遮挡和文字主导型作品可以更大。
- 视觉簇多数位于中部附近，但经常轻微偏上、偏下或偏向一侧；“绝对居中”不是规则。
- 作品常使用一条隐形轴线：横向文字线、竖向照片列、对角字母轨迹或两个照片窗口之间的连线。
- 画面不追求几何完美。轻微错位、边缘切断、文字跨越图像和不均匀间距提供手工感。

## 文字引擎

### 三种文字角色

每张海报先分配角色，再选择字体和布局。

1. **Primary hook（主句）**
   - 唯一需要清楚读懂的文字。
   - 中文通常 2-10 个字；英文通常 2-10 个词。
   - 不一定最大，但必须在第一次停留时被发现。

2. **Directional thread（方向线）**
   - 破碎单词、少量字母、重复字符或被截断的短语。
   - 作用是连接图像、制造方向和延长观看时间，不承担完整语义。

3. **Atmospheric field（氛围层）**
   - 极淡正文、旧书页、打字稿、模糊说明或重复段落。
   - 可以不可读，但必须形成真实的灰度面积，不能像随机水印。

作品通常使用两到三种角色。水果、静物和内容较完整的编辑页经常同时出现主句、辅助线与正文块；极端留白作品才会主动减少到一到两层。

### 平面构成：文字作为点、线、面

进一步对照水果、静物和照片类案例后，可以看到文字不是“补充说明”，而是与图像等价的平面材料。

- **点**：单独的关键词、极短标签和小型定位文字。它们面积很小，却能在空白中建立停顿和重心。
- **线**：单行句子、被主体打断的短语、沿图像边缘移动的词组。它们控制观看方向，连接两个原本分离的区域。
- **面**：由多行正文形成的灰色矩形块。正文首先被感知为面积和灰度，其次才被阅读。

成熟的案例往往同时使用三者：一个孤立词作为点，一条短句作为线，一个 3-8 行正文块作为面。它们不共享同一灰度：可读主句通常最深，辅助文字处于中灰，正文块接近纸面。文字内容并不单薄，只是通过字号、密度和灰度把信息压低。

### 文案内容规律

- 英文是高频的视觉语言，因为单词长度、大小写和字母节奏适合构成点、线、面。
- 文案通常包含一个可读观点、一句补充语义、一个正文段落和若干主题词，而不是只有主题名称。
- 文字碎片与正文应来自同一主题语义，形成可追溯的词汇家族；随机字母只能制造表面实验感。
- 正文块可以低对比、部分难读，但仍应具有真实语言的行长、词间距和段落轮廓。
- 作者签名、日期地点和天气属于原作者的个人出版系统，不应被当成通用风格组件复制。

建议生成层级：主句 `85%-100%`，辅助单行 `35%-60%`，正文块 `6%-18%`。Fruit 和 Still Object 默认使用完整点线面；Mood 和极端留白主题可以按需要减少一层。

### 八种文字行为及其频率

这些行为并非同样常见。公开作品的主体仍然是小字、淡字和局部穿插；大字纵轴与尺度冲撞只是少数例外，不能被当作默认风格。

高频默认：`micro-anchor-caption`、`horizontal-thread`、`ghost-body-layer`。

少量使用：`letter-field`、`image-interruption`、`edge-orbit`。

罕见例外：`vertical-spine`、`scale-collision`。只有主题本身以文字宣言或实验字体为核心时才考虑。

#### 1. `micro-anchor-caption`

一句很小的文字停在照片边缘、物件旁或视觉簇内部。它不是居中的图注，通常与锚点留有不对称距离。

适合：水果、静物、安静照片。

#### 2. `horizontal-thread`

文字从图像左侧开始，穿过或绕过照片，再从右侧离开。词与词之间有大间隔，部分字符被图像遮挡。

适合：海、夏天、关系、移动、炎热、时间。

#### 3. `letter-field`

少量字母、蓝点、星星或短字符分散在较大范围内。分布必须有密度变化和方向，不能均匀撒满。

适合：自由、向内生长、呼吸、夜晚、留白。

#### 4. `ghost-body-layer`

低对比正文形成一块灰色空气。正文可以在图像后方、左侧或跨越画面，但不应比主句更清晰。

适合：记忆、选择、暗处、长文情绪、档案感。

#### 5. `image-interruption`

一段可读文字被照片、色块、笔刷或裁切打断。遮挡产生含义，不是装饰。

适合：人物、自我定义、冲突、脆弱、凝视。

#### 6. `vertical-spine`

一条较长文字纵向旋转或沿画布高度生长，成为主要轴线。这是罕见例外；即使变大，也通常保持细字重或轻轮廓，周围必须克制。

适合：宣言、人物、长句、单一强概念。

#### 7. `edge-orbit`

文字沿照片边缘、圆形水果、人物轮廓或虚构轨道分布。轨迹不必闭合，通常只出现一段。

适合：水果切片、目光、花、太阳、圆点。

#### 8. `scale-collision`

一个较大的短句与极小正文、照片碎片发生尺度冲突。这是罕见例外，不能由生成器为了“实验感”自动选择；大字必须保持编辑感，不能变成粗黑商业标题。

适合：周末、选择、放下、明确态度、文字驱动主题。

### 文字密度规则

- 一张图只允许一个 Primary hook。
- 主句、方向线和氛围层的清晰度必须分级：`100% / 45%-70% / 5%-20%`，不要全部同样清楚。
- 如果主句很大，图像必须更小；如果图像已经占 20% 以上，主句应回到微型尺度。
- 不要把中文逐字等距排开。应按自然词组形成 1-3 个簇，再用空间断裂制造节奏。
- 随机字母必须来自主题词、主句拼音、日期语境或相关英文词根；不要生成无来源的乱码。
- 档案编号、天气和测量值不是默认装饰，只有主题明确需要时才出现。
- 同一画面最多两种字体家族。推荐“一种正文衬线/等宽 + 一种强调字体”。
- 默认使用小号、细字重、低对比文字。粗黑大字、巨大英文、角到角的斜向字带和大面积出界不是这套语言的常规特征。
- 面积较大的空心轮廓字只有在笔画极细、对比很低、视觉上仍像空气时才成立。

## 图像与文字的关系

- **图像先建立情绪，文字再改变解释**：例如海面可以表达平静，穿过海面的断裂文字让它变成距离或告别。
- **文字可以离开图像**：两者不必黏在一起。大段空白本身就是连接关系。
- **遮挡必须有语义**：人物被蓝色块遮住代表身份被覆盖；随意盖住一角只是装饰。
- **照片不是卡片组件**：避免统一圆角、投影、边框和“图片 + 标题 + 标签”的 UI 结构。
- **一张海报只保留一条主要运动方向**：横向、纵向、对角或环绕四选一。

## 图像处理

- 常见素材：树影、海面、天空、花、果实、局部人物、旧照片、简单线稿。
- 常见处理：低对比黑白、过曝、裁切、撕裂、双图拼接、照片窗口、半透明叠加、影印、网点。
- 清晰度集中在关键边缘。整体可以有扫描感，但主体轮廓和主句不能糊。
- 图像允许明显小，但不能弱到缩略图完全不可辨认。
- 完整场景通常被压缩成一块照片碎片，而不是重画成插画。

## 颜色系统

- 纸张不是单一灰白模板。可见体系包括奶油白、暖米、浅暖灰、冷白、石灰、灰绿和雾灰褐；泛黄只是其中一种，不是默认。
- 表面纹理也有变化：近乎纯哑光、细纤维、亚麻横纹、织纹、云斑、纸浆颗粒和稀疏石灰点。
- 纸面仍然服务于主体：纹理通常轻到中等，只有极简作品才让材质成为明显视觉事件。
- 正文：炭黑、灰黑、低对比灰。
- 高频强调：电光蓝、钴蓝、蓝紫。
- 主题强调：水果红、柠檬黄、橙色、浅青、柔绿。
- 强调色常占 0.5%-5%；`blue-signal` 和文字主导型作品可以放宽到 8%-14%。
- 颜色不是为了丰富画面，而是为了建立唯一记忆点或运动方向。

## 八种构图原型

1. `micro-photo-caption`：一个小照片窗口 + 偏置微型主句。
2. `dual-window-thread`：两个照片窗口 + 横向文字线。
3. `ghost-page-fragment`：幽灵正文 + 一个照片/花朵碎片。
4. `blue-signal-field`：蓝点或蓝字形成非均匀场。
5. `specimen-with-orbit`：水果/物件 + 局部环绕文字。
6. `obscured-portrait-axis`：人物局部 + 遮挡 + 纵向或横向文字轴。
7. `vertical-editorial-spine`：旋转大字 + 极小图像。
8. `scale-collision-page`：罕见例外，一句较大但细字重的文字 + 极小正文/图片形成尺度冲突。

## 常见失败模式

- 极端留白但没有视觉力线，只剩“空”。
- 小图和文字全部居中，像模板化文艺卡片。
- 用天气、日期、温度、编号填补不知道放什么的地方。
- 每个主题都使用蓝色散点，导致分类差异消失。
- 字符均匀撒开，没有密度、方向和来源。
- 为了可读把所有文字都排得同样清楚，丢失层级。
- 为了实验感加入太多字体、线条、数据和符号。
- 重度泛黄、颗粒和破损覆盖了作品本身。

## 使用边界

- 案例用于验证抽象规则，不作为图生图参考，也不要在 prompt 中写作者名。
- 不复制案例中的可识别句子、签名、账号名、日期组合或固定构图。
- 每次生成至少改变锚点、文字行为、方向、位置和色彩中的三项。
- 如果输出与某个单一案例过近，重新编译 prompt，而不是继续微调到更像。
